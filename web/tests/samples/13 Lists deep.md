# Lists deep

A paragraph followed directly by a list:
- first
- second

Loose list:

- loose one

- loose two

Ten and more:

8. eight
9. nine
10. ten
11. eleven

Tasks nested:

- [ ] parent task
    - [x] done child
    - [ ] open child with a long text that wraps onto a second row of the readable column to check the indent
        - plain grandchild
- [x] parent done
    1. ordered child
    2. second ordered child

Mixed bullets:

* star
    + plus nested
        - dash deeper

A list item with two paragraphs:

- The first paragraph of the item.

  The second paragraph of the item.
- Next item.

A quote with nested lists:

> - quoted bullet
>     - nested quoted bullet
> 1. quoted number

The end.
